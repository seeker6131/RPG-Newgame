# ⚔ มอนบุกหมู่บ้าน (Village Raid) — สเปกตามผู้กำกับ 2026-11-15

## ภาพรวม
- **หมู่บ้านกลาง** ของทั้งเซิร์ฟ (แผนที่อีเวนต์) มีอาคารกลาง 5 หลัง: 🪵 โรงไม้ (lumber) · 🍲 โรงครัว (kitchen) · ⚒ โรงหลอม (forge) · 🌾 ฟาร์ม (barn) · 🍺 เตี๊ยม (tavern)
- **อาคารกลางพัง = ทุกคนในเซิร์ฟใช้อาคารชนิดนั้นในหมู่บ้านตัวเองไม่ได้** จนกว่าจะช่วยกันซ่อมเสร็จ
- เวลา: **12:00 / 18:00 / 21:00 น.** (ไทย) · เตือน 5 นาทีก่อน (แถบทอง + ปุ่มเข้าร่วม) — เกิดทุกรอบ ไม่มีเกณฑ์คนขั้นต่ำ
- **ปรับตามจำนวนคนที่มาช่วย** (ผู้กำกับ): คนน้อย → มอนน้อยลง อ่อนลง ตีง่าย อาคารพังน้อย · คนเยอะ → ครบ 50–80 ตัว
  - ตัวอย่าง: 1 คน ≈ 15 ตัว (อ่อนลง 40%) · 3 คน ≈ 30 · 5 คน ≈ 45 · 8+ คน ≈ 60–80 ตัว
- **ไม่มีใครมาเลย**: อาคารเสียหายตามปกติ แต่ **ซ่อมตัวเองได้ช้าๆ** (เต็มในราว 6 ชม.) · ใครผ่านมาบริจาคก็เร็วขึ้นทันที

## ระหว่างบุก (3 นาที)
- มอน 50–80 ตัวเป็นคลื่น + บอสจอมทัพ พุ่งเข้าตีอาคารกลาง
- ห้องแยกตามช่วงเลเวล (1–30 / 31–60 / 61+) — มอนเลเวลตามห้อง
- มอนตีผู้เล่นได้ คนที่อ่อนกว่าตายได้ · **ตายแล้วดูอย่างเดียวจนจบ** แล้วฟื้นที่หมู่บ้านตัวเอง (ไม่เสียของ)
- อาคารเลือดเยอะ: ถ้าช่วยกันฆ่า **มอนตายหมดใน 3 นาที → พังแค่ไม่กี่หลัง (0–1)** · ป้องกันไม่ไหว / ไม่มีใครมา → พังหลายหลัง
- จบ: อาคารที่เลือด 0 = พัง · ที่เหลือฟื้นเต็ม

## ซ่อม (ศรัทธา)
- อาคารที่พังมีหลอดซ่อม เติมไม้/หิน/อาหาร/ทองเท่าไรก็ได้ ไม่จำกัดคน — หลอดเต็ม = ใช้ได้อีก
- **ราคาไม่โหด**: ทั้งเซิร์ฟช่วยกันไม่นานก็เสร็จ (ตั้งตามจำนวนผู้เล่นที่ออนไลน์จริง)
- กระดาน 🙏 ผู้ศรัทธา 10 อันดับ · คนเติมจนเต็ม ประกาศชื่อทั้งเซิร์ฟ · แต้มศรัทธาแลกของใช้ · อันดับ 1 รายสัปดาห์ได้ฉายา

## รางวัลคนป้องกัน
- ช่วยถึงเกณฑ์ (ฆ่า ≥ 5): 🎁 หีบผู้พิทักษ์ ×1 (ยา ผลึกมานา ยาบัพ ม้วน ตั๋วดัน โอกาสน้อยหีบเลือกอุปกรณ์ R/SR) + EXP + ทองเล็กน้อย
- MVP 1–3 ของรอบ: หีบ ×2 + ประกาศชื่อ
- ล้มเหลว: หีบเล็ก

## ความเสี่ยงที่แจ้งผู้กำกับแล้ว
- ช่วงคนน้อย → มอนปรับลดตามคน + อาคารซ่อมตัวเองช้าๆ
- โรงหลอม/โรงครัวพังกระทบหนัก → ราคาซ่อมต่ำ
- ค่าเซิร์ฟเพิ่มเล็กน้อย (วันละ 3 รอบ × 3 นาที)
